# 冲浪

> 空闲时自己上网刷一刷，挑值得分享的发给主人。

一个给 AstrBot 用的主动上网插件：主人一段时间没说话，机器人就自己去配置好的网站
（以及 B 站热门）看几条内容，读正文、记住，偶尔挑一条有意思的主动私聊分享。

## 功能概览

- **空闲触发**：主人私聊一段时间没新消息才动，聊天中不会插嘴
- **多来源**：自定义网站白名单 + B 站热门接口
- **随机网站**：每轮从白名单里随机抽几个，不会总盯着同一家
- **读多条、记多条**：每次挑 N 条读正文，全部写进阅读记忆
- **按概率分享**：读完按设定概率决定要不要说；说就只挑一条
- **两条消息**：先发标题 + 链接 + 配图，2 秒后发自己的想法
- **防重复**：链接去参数去重 + 话题相似度去重
- **屏蔽词**：标题或正文命中就跳过
- **失败补发**：发送失败存起来，5 分钟后自动重试
- **WebUI 面板**：状态、轮数、阅读记录、7 天统计、兴趣排行
- **记忆双写**：本地 JSON + 可选同步 livingmemory

## 工作原理

一次自动触发大致是这样：

```
每 60 秒检查一次（可配）
  ├─ 静默时段？           → 跳过
  ├─ 主人最近说过话？     → 跳过
  ├─ 今天轮数用完了？     → 跳过
  ├─ 有卡住的待补发？     → 先补发
  └─ 开始浏览
       ├─ 自定义网站随机抽 N 个 + B 站热门
       ├─ 过滤：看过的链接、重复话题、屏蔽词
       ├─ 让模型挑几条要读的
       ├─ 一次浏览器批量读正文（B 站走接口）
       ├─ 全部写进阅读记忆
       └─ 按概率决定分享不分享
            ├─ 分享：随机挑一条 → 生成想法 → 分两条发出
            └─ 不分享：只记，不打扰
```

手动 `/冲浪` 走简化流程：挑 1 条、读、带图发、写记录，不看概率、不占每日额度。

## 依赖

| 依赖 | 说明 |
|---|---|
| AstrBot | 4.24 及以上（需要插件视图能力） |
| Python | 3.10+ |
| Playwright + Chromium | 网页抓取，B 站接口不需要 |
| livingmemory | 可选，装了才同步阅读记忆 |

### 安装 Playwright

```bash
pip install playwright
playwright install chromium
```

**如果 AstrBot 跑在独立环境里**（比如 uv tool 或 docker），建议单独建一个 venv 装 Playwright，
然后在插件配置的 `browser_python` 填那个环境里的 python，避免污染 AstrBot 环境。

```bash
python3 -m venv /path/to/pwenv
/path/to/pwenv/bin/pip install playwright
/path/to/pwenv/bin/playwright install chromium
```

留空 `browser_python` 时，插件会用 AstrBot 自己的 python。

**ARM 设备**（香橙派、树莓派等）：`playwright install chromium` 会自动选择 arm64 版本，
插件自带的脚本会在 `~/.cache/ms-playwright/` 里自动查找浏览器，不需要手动指定路径。
也可以用环境变量 `PW_CHROME_PATH` 强制指定。

## 安装

1. 把 `astrbot_plugin_idle_browse` 整个目录放进 `data/plugins/`
2. 在 AstrBot WebUI 的插件页点「重载」
3. 打开插件配置，至少填这三项：
   - `target_qq`：分享给谁
   - `platform_id`：平台适配器 id
   - `persona_name`：机器人叫什么
4. 按需填 `custom_sites`、`blocked_words`
5. 面板在插件详情 → 视图 → `panel`

## 配置详解

### 基础

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用空闲冲浪 | 开 | 关掉后不抓取不推送，`/冲浪` 仍可用 |
| 人格名 | 空 | 填机器人的人格名，留空不自称 |
| 分享给谁（QQ 号） | 空 | 只发私聊给这个号，也是空闲判定对象 |
| 平台适配器 id | 空 | AstrBot 平台配置里的 id，用来拼私聊会话 |

### 触发

| 配置项 | 默认 | 说明 |
|---|---|---|
| 空闲多少分钟后去刷 | 60 | 主人私聊没新消息达到这个时长才触发 |
| 空闲怎么算 | owner_private | `owner_private` 只看主人私聊；`all` 所有会话 |
| 每天最多刷几轮 | 6 | 到上限当天不再自动刷；手动命令不受限 |
| 检查间隔（秒） | 60 | 后台多久检查一次 |
| 静默开始 / 结束（小时） | 1 / 7 | 支持跨零点；两者相同表示不设静默 |

### 来源

| 配置项 | 默认 | 说明 |
|---|---|---|
| 自定义网站 | 空 | 每行 `名称|网址`，只保留同域名链接 |
| 每轮随机几个网站 | 3 | 从白名单随机抽这么多个，B 站不占名额 |
| 每轮候选总数 | 20 | 所有网站加起来最多这么多条 |
| 抓 B 站热门 | 开 | 用热门接口取视频，读简介、评论、封面 |
| B 站取多少热门 | 10 | 每轮取这么多个参与挑选 |
| B 站 SESSDATA | 空 | 填了才能拿字幕；留空只读简介和评论 |

**自定义网站写法**：

```
少数派|https://sspai.com/
澎湃|https://www.thepaper.cn/
腾讯新闻|https://news.qq.com/
```

名称可以省略，只写网址；以 `#` 开头的行会被忽略。

### 分享

| 配置项 | 默认 | 说明 |
|---|---|---|
| 每次读几条 | 3 | 挑这么多条读正文，全部记进阅读记忆 |
| 分享概率 | 0.3 | 读完按这个概率挑一条分享；设 0 就只记不说 |
| 分享语气 | 见配置 | 描述该怎么说话，每台机器可各配各的 |
| 话题重复阈值 | 0.62 | 0~1，越大越不容易判重 |
| 屏蔽词 | 空 | 每行一个，标题或正文命中就跳过 |

### 记忆

| 配置项 | 默认 | 说明 |
|---|---|---|
| 保存到自己的阅读记忆 | 开 | 独立文件 `reading_memory.json` |
| 本地记忆最多保留多少条 | 100 | 超出只留最近的 |
| 同步到 livingmemory | 开 | 装了且有记忆引擎才写，失败不影响本地 |

### 高级

| 配置项 | 默认 | 说明 |
|---|---|---|
| 判断用的模型提供商 | 空 | 留空用默认，例如 `deepseek/deepseek-flash` |
| 正文读取字数 | 2500 | 每条正文最多读这么多字 |
| 浏览器 venv 的 python | 空 | 留空用 AstrBot 的 python |
| 四个脚本路径 | 空 | 留空用插件自带 `scripts/` |

## WebUI 面板

插件详情里打开 `panel`：

## 数据文件

都在 `data/plugin_data/astrbot_plugin_idle_browse/`：

| 文件 | 内容 |
|---|---|
| `reading_memory.json` | 阅读记录（时间、标题、链接、来源、想法） |
| `seen.json` | 看过的链接（去参数后） |
| `topics.json` | 推过的话题签名 |
| `daily.json` | 当天轮数 |
| `feedback.json` | 兴趣分 |
| `last_share.json` | 最近一次分享 |
| `pending_send.json` | 待补发 |
| `status.json` | 当前状态 |

删掉对应文件即可重置那部分数据，插件会自己重建。

## 常见问题

**Q：为什么一直显示「空闲」，不去浏览？**
主人最近说过话，空闲计时被重置了。把 `空闲多少分钟` 临时改成 1 测试，或者先别跟它说话。

**Q：面板显示「读取失败 / bridge 未注入」？**
必须从 AstrBot 的插件视图打开（`#/plugin-view/...`），直接访问静态文件不会注入 bridge。

**Q：图片发不出来？**
网页需要 `og:image` 或正文首图，B 站用封面。图片地址会自动转 https。如果日志里
`发送带图=True` 但还是收不到，是 QQ 端图片上传的问题。

**Q：B 站字幕拿不到？**
需要填 `SESSDATA`（浏览器登录 B 站后 Cookie 里的值）。这是账号凭证，只填在本机配置里。

**Q：会不会重复推同一条？**
链接会去参数后比对，话题会用相似度比对（默认 0.62），读过的链接都会记下来。

**Q：一次要花多少 token？**
一次自动浏览大约 3 次模型调用（挑选、写想法、偶尔补判），其余是浏览器抓取不花 token。
分享概率越低，模型调用越少。

## 已知限制

- **百度热搜**：条目点开是搜索结果页，读不出正文，不建议加
- **IT之家 / 36氪**：首页会混入搜索页、子站链接，可能白读一条
- **B 站字幕**：需要 `SESSDATA`，不填只有简介和评论
- **屏蔽词**：字面匹配，同一件事换个说法可能漏
- **反爬站点**：小红书、抖音、微博热搜这类抓不到
- **图片**：取 `og:image`，没有就不带图
- **浏览器**：每条正文要真实打开页面，慢且吃内存，所以每次限制读几条
